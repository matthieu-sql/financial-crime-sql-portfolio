# Suspicious Transaction Monitoring

## Business Scenario

A financial institution wants to identify customers exhibiting potentially suspicious transaction activity that may require review by the Fraud or AML Investigation team.

The objective is to identify customers whose transaction behavior deviates from normal patterns based on transaction amount, transaction frequency, and geographic activity.

---

## Business Objective

Develop SQL queries that help investigators:

- Identify high value transactions
- Detect unusual transaction velocity
- Identify customers with elevated cumulative transaction amounts
- Support fraud investigations and AML monitoring

---

## Skills Demonstrated

- SQL
- Aggregations
- GROUP BY
- HAVING
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Risk Analytics
- Fraud Detection
